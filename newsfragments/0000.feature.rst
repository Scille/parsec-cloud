- Adding 3 global arguments:
  - ``--format={plain,json}`` control how the output data is formatted (default to ``JSON``)
  - ``--color={auto,always,never}`` to stylize message & data (default to ``auto``)
  - ``--progress={quiet,plain,spinner}`` how progress are shown (default to ``spinner`` on a TTY else ``plain``)
